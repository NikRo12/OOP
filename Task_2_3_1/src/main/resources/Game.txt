Model:
    1) GameField
        Поля:
            1) Список интерфейсов еды (интерфейсов для того чтобы можно было потом добавить разную еду)
            2) Список объектов змеек (какая то часть в будущем будет ботами)
            3) Скорость игры
            4) Возможно понадобится что то еще
        Методы
            1) Start(speed) - бесконечный цикл, c тиком speed в каждый момент времени у змеек будет вызваться метод move(int x, int y), который возвращал бы ее чтобы изменить их внутренне состояние,
                а в поле изменить положение змеек и проверить попадание в препятствие. Будет также проверяться количество еды, и, если нужно, то генерироваться случайная еда и отображаться.
                Если змейка совпала с едой, у змейки буду вызываться метод eat(food Food) для изменения внутреннего состояния змейки. Если змейка достигала бы длины L, она бы выбрасывала исключение WIN для завершения бесконечного цикла в GameField
            2) UserHandler - пользовательский ввод, для вызова методы move() у змейки пользователя
    2) Snake
        Поля:
            1) Связный список звеньев - тело, у каждого звена есть 4 соседа
            2) Возможно что то еще
        Методы:
            1) move(int x, int y) - движение змейки, то есть изменение соседей для необходимых звеньев
            2) eat() - увеличение количества звеньев
    3) Классы еды (имплементируют интерфейс Food)
        Поля: можно разное придумать
        Методы: методов нет я думаю
    4) Obstacle
        Поля: по сути просто размер
        Методы: не нужны
